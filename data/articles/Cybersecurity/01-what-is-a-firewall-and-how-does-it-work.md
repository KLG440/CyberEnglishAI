---
title: "What is a Firewall and How Does It Work?"
category: Cybersecurity
difficulty: Intermediate
---

A firewall is a network security device that monitors and controls incoming and outgoing network traffic based on predetermined security rules. It acts as a barrier between a trusted internal network and untrusted external networks, such as the Internet.

Firewalls can be hardware-based, software-based, or a combination of both. Hardware firewalls are physical devices that sit between your network and gateway. Software firewalls are programs installed on individual computers.

There are several types of firewalls:
1. Packet filtering firewalls examine packets and block them based on source and destination IP addresses and ports.
2. Stateful inspection firewalls track the state of active connections.
3. Next-generation firewalls combine traditional capabilities with features like encrypted traffic inspection and intrusion prevention systems.

Key vocabulary: firewall, network, traffic, packet, inspection
